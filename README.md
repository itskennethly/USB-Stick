# 🔍USB-Stick

Designed a custom USB storage device from scratch using KiCad. The project involved designing a PCB that integrates a USB-A port, USB2244-AEZG-06 USB controller, MicroSD card interface, LED, and MCP1700-3302E voltage regulator.

---

💻Software & Tools
- KiCard (Schematic Design & PCB Layout)

🔧 Hardware Components
- USB-A Connector
- USB2244-AEZG-06 USB Controller
- MicroSD Card Interface
- LED
- MCP1700-3302E Voltage Regulator

🔨Skills Demonstrated
- PCB Design
- Electronic Circuit Design
- Schematic Capture
- Component Integration
- Hardware Design
